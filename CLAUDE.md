# Project Chateau

HOA system for Chateau Real Executive Village. There are two apps on one shared Supabase backend:

- `mobile/`: the Flutter app for residents (Android first). See `mobile/PRODUCT.md` and `mobile/README.md`.
- `chateau-project/`: the web admin app for HOA officers.

## Agent skills

### Issue tracker

Issues live in GitHub Issues on MicoMick/Project-Chateau, managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The default five-role vocabulary (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` plus `docs/adr/` at the repo root. See `docs/agents/domain.md`.
